# Geometric figures

## Math formulas
### Area
- Circle: S = πR²
- Rectangle: S = ab
- Square: S = a²

### Perimeter
- Circle: P = 2πR
- Rectangle: P = 2a + 2b
- Square: P = 4a

## Function documentation
### circle.py
- `area(r)` - calculates the area of a circle given its radius.
- `perimeter(r)` - calculates the circumference of a circle given its radius.

### square.py

- `area(a)` - calculates the area of a square given its side length.
- `perimeter(a)` - calculates the perimeter of a square given its side length.
